# Fix Wi-Fi or internet not connecting
Keywords: wifi, wi-fi, internet, network, connection, disconnecting, offline, no internet
Steps:
1. Turn Wi-Fi off and on again, or switch airplane mode on and off.
2. Choose the company network and enter your credentials again.
3. Restart the laptop.
4. Check if other colleagues in the same room have the same problem.
5. If several people are affected, create a ticket marked "network" with the room and the time it started.
If this does not work: connect with a network cable if possible and create a ticket.
