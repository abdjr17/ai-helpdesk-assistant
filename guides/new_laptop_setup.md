# Set up a new laptop for a new team member
Keywords: new laptop, new starter, new colleague, onboarding, setup, set up, workplace, new employee, device
Steps:
1. Check the request form for the user name, department and start date.
2. Update the operating system and install the standard software list.
3. Create the user account and add the user to the department groups.
4. Turn on disk encryption and the screen lock.
5. Add the device to the asset list with serial number, user and location.
6. Test email, VPN and printing, then hand over the laptop with a short checklist.
If this does not work: create a ticket and attach the asset list entry.
