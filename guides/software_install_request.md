# Request software installation
Keywords: software, install, installation, program, application, app, license, licence, download
Steps:
1. Check the approved software list. If the program is on the list, request it in the self-service portal.
2. If it is not on the list, create a ticket with the program name, the reason and your manager's name.
3. IT checks security and licences. This can take a few working days.
4. After approval, IT or the portal installs the program.
Do not install software from unknown websites.
If this does not work: contact the IT team through a ticket and mention the ticket number of your request.
