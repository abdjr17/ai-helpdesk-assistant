# Report a lost or stolen device
Keywords: lost, stolen, theft, missing, laptop, phone, tablet, device, security
Steps:
1. Report it immediately. Do not wait until the next day.
2. Create an urgent ticket with the device type, the time and the place where you lost it.
3. IT locks the account and, if possible, wipes the device remotely.
4. Change your password from another device.
5. If it was stolen, also report it to the police and send IT the report number.
If this does not work: call the IT phone line and say it is a lost device case.
