# POS cash register is frozen or shows an error
Keywords: pos, cash register, register, checkout, till, scanner, frozen, billing, receipt, payment, card terminal
Steps:
1. Do not restart in the middle of a payment. Wait one minute first.
2. Check the network cable and the power cable of the register.
3. Check whether the card terminal is connected and shows its home screen.
4. Restart the POS application, then the register if needed.
5. Use the backup register or the manual process while the problem is open.
6. Write down the time and the error message.
If this does not work: create an urgent ticket with the store name, register number, time and error message.
