# Request access to a shared folder or drive
Keywords: access, shared drive, shared folder, folder, permission, permissions, rights, share, team drive
Steps:
1. Ask the folder owner or your manager to approve the access.
2. Create a ticket with the folder name, the path and the type of access (read or edit).
3. Add the approval from your manager to the ticket.
4. IT sets the permission and tells you when it is done.
Access is given only as long as it is needed.
If this does not work: ask the folder owner to check the permission list.
