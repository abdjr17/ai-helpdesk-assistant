# Computer is slow
Keywords: slow, performance, freezing, lag, laggy, memory, restart, speed, hang
Steps:
1. Save your work and restart the computer. Many problems disappear after a restart.
2. Close programs and browser tabs you do not need.
3. Check for pending updates and install them.
4. Check free disk space. Delete files you no longer need.
5. Check whether the slowness happens in one program only.
If this does not work: create a ticket and write which program is slow and since when.
