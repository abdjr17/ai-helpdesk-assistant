# Printer shows offline
Keywords: printer, printing, print, offline, paper, queue, scanner
Steps:
1. Check that the printer is on and shows no error on its display.
2. Check paper and toner.
3. On your computer, open the print queue and delete stuck jobs.
4. Select the printer again as default and print a test page.
5. Restart the printer and wait two minutes.
If this does not work: create a ticket with the printer name, the printer location and the error shown on its display.
